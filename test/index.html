Entorno de Pruebas

Extensión Chrome: Lector de Códigos QR

👉 Instrucciones de prueba:
1. Pulsa el botón de la extensión en la barra superior para entrar en Modo Selección.
2. Detección Automática: Verás que la extensión resalta automáticamente los códigos QR presentes con un recuadro verde iluminado. Haz clic en cualquiera para seleccionarlo.
3. Selección Manual: Haz clic y arrastra con el ratón sobre cualquier área para recortar manualmente.
4. El popup.html se abrirá con el tipo de datos detectado y botones de acción (abrir pestaña, copiar texto, copiar clave wifi, etc.).

1. Enlace Web (URL)

Al escanearlo, ofrecerá abrir en pestaña nueva o copiar el enlace.

https://github.com/yabbadabbadev/qr-reader.chrome-extension

2. Red Wi-Fi (WIFI:...)

Ofrecerá mostrar/ocultar contraseña, copiar clave y copiar credenciales completas.

WIFI:S:DemoWiFi_5G;T:WPA;P:SuperPasswordDemo123!;;

3. Correo Electrónico (mailto:)

Ofrecerá redactar correo al destinatario o copiar dirección.

mailto:demo@example.com?subject=Prueba%20QR%20Reader&body=Hola!

4. Teléfono (tel:)

Ofrecerá llamar al número o copiarlo al portapapeles.

tel:+34912345678

5. Texto Plano

Texto formateado para previsualizar y copiar directamente.

Este es un código QR de prueba con texto plano escaneado exitosamente.

🎬 Simulación de Fotograma / Vídeo

Este código QR está integrado en un banner con degradado complejo para verificar que la captura y detección de píxeles funciona sobre cualquier fondo o animación.
